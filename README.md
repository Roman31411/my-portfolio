# Моё портфолио

Простой и адаптивный сайт-портфолио начинающего веб-разработчика с возможностью переключения тем оформления.

## Использованные технологии
* **HTML5** — структура страницы и семантическая разметка
* **CSS3** — стилизация, Flexbox-сетка для карточек и анимация наведения
* **JavaScript (Vanilla JS)** — логика динамического переключения светлой и тёмной темы
